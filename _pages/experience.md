<h3>research</h3>

<p><b>Senior Honors Thesis</b>, Williams College <span style="float:right">May 2025 &ndash; May 2026</span><br>
<i>The Effect of Class Imbalance on Causal Effect Estimation</i> &mdash; advised by <a href="https://rohit-bhattacharya.com/">Prof. Rohit Bhattacharya</a></p>
<ul>
  <li>Showed that standard class imbalance techniques (undersampling, oversampling, class weighting) introduce implicit selection bias that violates conditional exchangeability, invalidating average causal effect estimates.</li>
  <li>Formulated reweighted augmented inverse probability weighting (rAIPW), a new estimator that corrects this bias and gives consistent treatment effect estimates.</li>
  <li>Validated rAIPW across 200+ simulated and real-data experiments at six dataset sizes, recovering estimates to within 1% of the true value.</li>
  <li>Awarded Highest Honors. <a href="/thesis/" target="_blank" rel="noopener">[thesis]</a></li>
</ul>

<p><b>Missing Data in Federated Learning</b>, Williams College <span style="float:right">Spring 2025</span></p>
<ul>

  <li>Explored propensity-based corrections for underrepresented clients and began translating the approach into an implementation using the Flower federated learning framework.</li>
</ul>
